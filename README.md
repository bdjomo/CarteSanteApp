# CarteSanteApp

Eine C# / .NET Anwendung zur Verwaltung von Gesundheitskarten und Kundendaten.

## Features
- Anbindung an PostgreSQL-Datenbank
- Benutzerverwaltung und Rollenrechte
- Verwaltung von Kundendaten (Clients)

## Technologien
- C# / .NET
- Entity Framework Core
- PostgreSQL
